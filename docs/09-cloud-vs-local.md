# 9. Cloud vs. Local — When to Use Which

Local AI is not always the right choice, and cloud AI is not the enemy. Use this section to decide.

## Use local when

- Privacy matters (you are writing personal, business, or client material)
- You want no monthly bill
- You have spotty or metered internet
- You want the model available at 3 a.m. with no account
- You are learning and want to experiment without pressure

## Use cloud when

- You need the smartest available model for a one-off hard task
- Your hardware cannot run even a small model acceptably
- You need features local tools do not offer (image generation, web browsing, voice)
- You are okay with a company seeing your input (read their terms first)

## A practical hybrid approach

Many people use both: a small local model for daily drafting and privacy-sensitive work, and a cloud model for occasional heavy lifting. You are not choosing one forever — you can switch task by task.

## Cost comparison (rough)

| | Local | Cloud subscription |
|---|---|---|
| Ongoing cost | $0 | $0–$30/month |
| Hardware cost | Uses what you own | None |
| Internet after download | None | Required every message |
| Privacy | You control it | Provider sees input |
