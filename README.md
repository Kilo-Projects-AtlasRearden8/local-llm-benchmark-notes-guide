# Running Local LLMs on a Home PC — A Beginner Manual

A plain-English, step-by-step guide to choosing, installing, and running large language models (LLMs) entirely on your own computer — no cloud account, no monthly bill, and your data never leaves your house.

## Quick start (the friend's version)

If you just want to try it right now:

1. Download **Ollama** from ollama.com (Windows, Mac, or Linux).
2. Open a terminal and run: `ollama run llama3.2:1b`
3. Start typing. That's it — the model is running locally on your machine.

See `docs/04-ollama-setup.md` for the full walkthrough.
